Data Syncer.

Copy or upsert whole tables between databases saved in the Vault — in resumable chunks. Progress is saved after every chunk, so you can stop and start any time. This page never shows table data, only progress.

Projects

A project = one source, one target, a set of tables with keys, and the saved position of each table.

New project

Connections come from the Vault — add or change them there. Nothing is typed here.

Upsert
Insert new rows, update changed ones, leave unchanged rows alone. Safe to re-run on a target that already has data. Needs a key and a unique index on it in the target.
Copy
Fastest: raw bulk load, no row handling, no transformation. Target tables must be empty (or truncated first). Key is only used to make it resumable.

Tables

Tick the tables to sync. The key (one or more columns, comma-separated) is pre-filled from the primary key. Key columns must never be NULL — a NULL key row would be skipped silently, so the syncer checks and refuses.
