1. Choose your owner PIN

The PIN is needed to allow changes and to resume after a stop. It keeps an AI that can run commands on this machine from giving itself permission. Stopping never needs the PIN. Choose something only you know (at least 6 characters). If you forget it, run python -m mcp_server set-pin after clearing it in the database — so write it down.

Permissions to change things

Each permission is for one connection, server or workspace, for a limited time. When it ends the AI is read-only again. There is no permission to delete or drop anything.
