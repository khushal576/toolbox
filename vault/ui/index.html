Vault.

One place for what Toolbox keeps: 🔑 Secrets (connections, servers, keys — encrypted at rest) and 📦 Data (workspaces → tables, stored as Parquet). See vault/CLAUDE.md for the trust model.

Workspaces

Like Glue databases: group tables, e.g. migration_staging. Tables are named workspace.table everywhere.

    Pick a workspace

    Tables are stored as Parquet in Toolbox's storage (fast to query). Loading files into tables: Data Lake tool. Duck Lab, DataFrame Studio, SQL Studio and DataDiff load from / save to here.

      Add connection

      Save a database connection here instead of typing it into a tool each time. It appears under "Saved connections (Vault)" in SQL Studio and Schema Map. Stored encrypted.

      Add SSH server

      For the SSH & SFTP tool: browse files, upload and run commands. A private key is safer than a password. First you confirm the server's fingerprint, so your login is never sent to an impostor; after that the tool refuses any server that presents a different key. Stored encrypted.

      Confirm this server's fingerprint
      Compare it with the one the server's administrator gives you (or run ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub on the server). Only continue if they match.

      Backup & restore

      The Docker volume this data lives on already survives an ordinary rebuild/restart — this is a REAL, portable copy you can keep somewhere else entirely (another disk, cloud storage, a different machine), for the one case that doesn't survive: an explicit volume deletion.

      Clear vault

      Permanently deletes every saved secret. Cannot be undone.
