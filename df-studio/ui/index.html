Full pandas + numpy (pd, np) in scope. Must return a DataFrame. No sandboxing — it's your own code, on your own machine. Vectorized pandas (whole-column operations) stays fast at any row count; row-by-row code like df.apply(lambda row: ..., axis=1) or iterrows() runs a Python function per row and can get slow on large files — prefer vectorized operations where possible.
