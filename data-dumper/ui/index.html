Data Dumper.

Take a Postgres dump you can download, and restore a dump into any database — all of it, or just the part you choose: structure, data, a phase, some schemas, some tables, or single objects. Connections come from the Vault.

Dumps

Each dump is a file kept on this server until you delete it. Download it, or restore it into any database.

Take a dump

A consistent snapshot of the whole database (other work can continue meanwhile). Nothing is changed in the source.

Custom (.dump) — recommendedCompressed. Restores with pg_restore and lets you restore only part of it.
Plain SQL (.sql.gz)Readable SQL, gzip-compressed. Runs anywhere with psql, but restores whole only.
EverythingStructure and data.
Structure onlyTables, indexes, views, functions… no rows.
Data onlyRows only. Restores into a target that already has the tables.

Upload a dump

A custom-format .dump, a .sql or a .sql.gz file made by pg_dump anywhere. It is checked and added to the list above.

Restore

Into which database, and what to restore. Nothing runs until you press Restore, and everything runs in one transaction: any error rolls it all back.

What to restore

EverythingStructure and data. The target must be empty.
Structure onlyAll definitions, no rows.
Data onlyRows into tables that already exist.
Phase 1 · before dataTables, types, functions, sequences.
Phase 2 · dataThe rows (into the phase-1 structure).
Phase 3 · after dataIndexes, constraints, triggers. Loading data before indexes is much faster.
Choose schemasEverything inside the schemas you tick.
Choose tablesTables with their indexes, constraints, sequences, partitions.
Choose objectsAny single item: one index, one view, one function…
