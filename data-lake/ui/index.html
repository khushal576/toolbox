Data Lake.

Load files into Vault Data tables — one file or thousands, CSV/TSV, JSON/JSON Lines, Parquet, XML, Excel, also .gz. Everything is converted to Parquet (fast, compact) in the background, so even multi-GB files never fill memory. Then query them with SQL — joins across workspaces, results you can page, download or save as a new table. Browse tables in Vault → 📦 Data.

1 Where is the data?

Drop files here or choose files — several files of the same kind become one table

Files in your shared data folder (~/toolbox-data on this machine, read-only). Click a file or folder, or type a pattern.

Copy tables from a database saved in the Vault (Postgres, SQL Server, Oracle — SSH tunnels work) into a workspace, e.g. to stage data for a migration. The database is only read.

Pick a connection, then “Show tables”.

Files in an AWS S3 bucket (or any S3-compatible storage). Credentials are kept encrypted in the Vault as an S3 location.

Downloaded once by the worker, then loaded like an upload.

2 Into which table?

Names: lowercase letters, digits and _. The table will be workspace.table.

Advanced: format, header, delimiter…
